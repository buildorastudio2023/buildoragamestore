Publiez votre jeu sur Buildora.

Vous avez créé un jeu et souhaitez le proposer au catalogue ? Envoyez-nous les informations nécessaires. Chaque proposition est examinée avant une éventuelle publication.

Comment proposer votre jeu ?

  1. 1
    Préparez votre jeu

    Le jeu doit fonctionner correctement dans un navigateur. Envoyez le fichier HTML et les autres fichiers nécessaires à son fonctionnement, si le jeu en utilise.

  2. 2
    Présentez votre projet

    Indiquez le nom du jeu, une description, les commandes et les éventuelles conditions nécessaires pour y jouer.

  3. 3
    Envoyez votre proposition

    Contactez-nous par e-mail et joignez les fichiers de votre jeu. Vous pouvez également fournir une image de présentation.

  4. 4
    Attendez notre réponse

    Nous vérifions notamment le fonctionnement du jeu, les informations fournies et les droits associés avant de décider si nous pouvons le publier.

Informations à fournir

  • Nom du jeu : le titre à afficher dans le catalogue.
  • Description : quelques phrases pour présenter le jeu.
  • Fichiers du jeu : le fichier HTML et les éventuels fichiers associés, idéalement regroupés dans une archive ZIP si nécessaire.
  • Nom du créateur : facultatif, si vous souhaitez qu'il soit affiché sur la page du jeu.
  • Illustration : facultative, pour présenter le jeu dans le catalogue.
  • Catégorie : facultative, par exemple réflexion, arcade ou simulation.

Avant d'envoyer votre jeu

  • Vous devez disposer des droits nécessaires sur le jeu et ses ressources, ou avoir l'autorisation de les utiliser.
  • N'incluez pas de données personnelles, de mots de passe ou de clés secrètes dans les fichiers transmis.
  • Précisez si le jeu dépend d'une connexion Internet, d'un service externe ou d'autres fichiers.
  • L'envoi d'une proposition ne garantit pas son acceptation ni sa publication.

Rémunération

Buildora Game Store ne propose actuellement aucune rémunération pour les jeux soumis. Une éventuelle évolution du service, notamment l'intégration de publicités ou d'un système de revenus, dépendra des démarches nécessaires, des autorisations applicables et des conditions qui seront définies à ce moment-là. Aucune rémunération future n'est garantie.

À savoir : le bouton ci-dessous ouvre votre application de messagerie. Vous devrez ajouter vous-même le fichier HTML ou l'archive ZIP en pièce jointe avant d'envoyer votre e-mail.
