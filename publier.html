Espace créateurs

Publiez votre jeu sur Buildora.

Vous avez créé un jeu ? Envoyez-nous votre proposition. Chaque jeu est examiné avant une éventuelle publication.

Comment proposer votre jeu ?

  1. 1
    Préparez les fichiers

    Joignez le fichier HTML et tous les fichiers nécessaires au jeu. Vous pouvez les regrouper dans une archive ZIP.

  2. 2
    Présentez votre projet

    Indiquez le titre, une description, les commandes et les éventuelles dépendances.

  3. 3
    Envoyez votre e-mail

    Ajoutez les fichiers en pièce jointe et précisez le nom du créateur si vous souhaitez qu'il apparaisse sur le site.

  4. 4
    Attendez la vérification

    La publication n'est pas automatique. Nous examinons les fichiers et les informations avant de décider si le jeu peut être ajouté.

Informations à fournir

  • Nom du jeu et description.
  • Fichiers du jeu : HTML et fichiers complémentaires.
  • Nom du créateur : facultatif.
  • Icône : facultative, idéalement carrée.
  • Image de présentation : facultative, pour la couverture de la carte.
  • Catégorie : facultative.

Conditions de soumission

  • Vous devez disposer des droits nécessaires sur le jeu et ses ressources.
  • N'incluez aucune clé API, aucun mot de passe ni donnée confidentielle dans les fichiers.
  • Le jeu ne doit pas contenir de code malveillant ou de collecte cachée de données.
  • L'envoi ne garantit ni l'acceptation ni la publication.

Rémunération

Aucune rémunération n'est actuellement proposée. Toute évolution future, notamment l'ajout de publicités ou d'un système de revenus, dépendra des démarches, autorisations et conditions applicables. Aucune rémunération future n'est garantie.

Important : le bouton ouvre votre application de messagerie. Vous devrez joindre vous-même le fichier HTML ou l'archive ZIP avant d'envoyer le message.
