Comment jouer ?

Choisissez un jeu dans le catalogue puis cliquez sur « Jouer ». Le jeu s'ouvre dans un nouvel onglet. Certains jeux peuvent nécessiter une connexion Internet.

+

Publier un jeu

Vous pouvez proposer votre jeu avec son nom, sa description et ses fichiers. Consultez la page de publication pour connaître la procédure.

↻

Jeu absent ou inaccessible

Un jeu peut être temporairement indisponible si ses fichiers ont été déplacés ou si son hébergement rencontre un problème. Contactez-nous pour signaler un lien cassé.

Règles et informations importantes

Contenu : les jeux ne doivent pas contenir de code malveillant, de collecte cachée de données ou de ressources utilisées sans autorisation.

Sécurité : ne partagez pas de mots de passe, de clés API ou d'autres informations confidentielles dans les fichiers ou les messages.

Données personnelles : limitez les informations envoyées à celles nécessaires au traitement de votre proposition.

Disponibilité : le catalogue dépend de l'accès au fichier de données et à l'hébergement des jeux. La disponibilité permanente n'est pas garantie.

Évolution du service : les fonctionnalités et les conditions peuvent évoluer. Les changements seront présentés sur le site lorsqu'ils seront mis en place.
